# Code of Conduct

We are committed to a respectful, inclusive, harassment-free project environment.

Expected behavior includes constructive technical discussion, reproducible evidence, respect for different expertise, and transparent correction of mistakes. Harassment, discrimination, personal attacks, publication coercion, credential exposure, and fabrication of results are unacceptable.

Report conduct concerns privately to the repository maintainers. Maintainers may edit, remove, or reject contributions and participation that violate this policy. Enforcement decisions should protect affected participants and document actions proportionately while respecting privacy.
